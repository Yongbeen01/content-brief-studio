# Content Brief Studio

브랜드 자료와 컨셉을 넣으면 TikTok 크리에이터용 영상 컨텐츠 가이드(기획서)를 만들어 주고,
미리보기에서 말로 다듬은 뒤 노션 **Contents Guidline** 아래에 새 페이지로 올려 주는 PC 프로그램입니다.

- 글은 각자 PC 의 **Claude** 가 씁니다(내 Claude 구독으로 로그인 — API 키 없음).
- **미리보기는 한국어**로 보고 고치고, **노션에 올릴 때 영어로** 바뀝니다.
- 형식과 어조는 [docs/brief-template-guide.md](docs/brief-template-guide.md) 를 그대로 따릅니다.
- 화면 모양은 TikTok Final Report 플러그인과 같습니다.

## 설치 (처음 한 번)

1. 관리자에게 받은 **install.bat** 을 두 번 누릅니다(케비서 「프로그램 다운로드 센터」에서 설치해도 됩니다).
   또는 PowerShell 에 이 한 줄:
   ```powershell
   irm https://raw.githubusercontent.com/Yongbeen01/content-brief-studio/main/scripts/install.ps1 | iex
   ```
   관리자 권한이 필요 없습니다. Node·git·Claude Code 가 없으면 알아서 받습니다.
2. 설치 중에 **Claude 로그인** 창이 뜨면 브라우저에서 로그인합니다(Claude Pro/Max/Team 구독 필요).
3. 앱이 열리면 오른쪽 위 **[노션 설정]** → 관리자에게 받은 **팀 설정 코드**(`CBS1.`로 시작)를 붙여넣습니다.
   이어서 뜨는 노션 승인 화면에서 **Contents Guidline** 페이지를 선택하고 허용합니다(사람마다 한 번).
4. 오른쪽 위 **[Kglowing API]** → 관리자에게 받은 **X-API-KEY** 를 붙여넣고 [확인하고 저장]. 맞는 키인지 확인한 뒤 이 PC 에만 저장됩니다.
   이 키가 있어야 캠페인 목록에서 Account ID·업로드폼 링크를 가져옵니다(없으면 두 칸을 직접 넣습니다).

다음부터는 바탕화면의 **Content Brief Studio** 아이콘으로 엽니다. 새 버전은 30분마다 알아서 받습니다.

## 쓰는 법

왼쪽 맨 위 탭에서 고릅니다.

- **새로 생성** — 자료·소구점·컨셉으로 Claude 가 새로 씁니다(아래 1~5).
- **기존 브리프 업로드** — 이미 만든 브리프를 **그대로** 옮겨 바로 미리보기로 보여 줍니다. 그다음은 새로 만든 것과 똑같이 고치고 노션에 올립니다.
  - **노션 링크**를 붙여넣고 [불러오기] — 몇 초면 글이 뜨고, 사진·GIF 는 받는 대로 채워집니다(움직이는 GIF 그대로).
  - **PDF**(노션 → ⋯ → 내보내기 → PDF)를 [PDF 첨부] — Claude 가 글자 그대로 옮겨 적어 2~3분 걸립니다(5쪽 기준).
    링크 주소와 사진은 PDF 에서 직접 꺼냅니다. PDF 의 GIF 는 첫 장면만 담긴 정지 사진이라, 움직이는 GIF 가 필요하면 노션 링크로 불러오세요.
  - 스텝·Do's/Don'ts·가이드 표처럼 알아볼 수 있는 곳은 칸별로 고칠 수 있게 나누고, 나머지는 원래 모양 그대로 둡니다.
    원본의 소제목·항목 이름(예: `❤️ Action`, `Mandatory Caption`)도 그대로 살립니다.
  - 영어로 된 브리프는 영어 그대로 보여 줍니다. 고친 곳에 한국어를 쓰면 노션에 올릴 때 **그 줄만** 영어로 옮깁니다.

1. 왼쪽 칸을 채웁니다. 별표(*)는 필수이고, 비운 채 [생성]을 누르면 빈 칸이 붉게 깜빡입니다.
   - **캠페인**: 파이널 리포트처럼 검색되는 드롭다운입니다(브랜드·캠페인명·번호, 띄어쓰기로 여러 낱말). 고르면
     **Account ID** 와 **업로드폼 링크**를 캠페인 정보에서 가져옵니다 — 업로드폼은 그 캠페인의 리마인드·땡큐레터 메일에 적힌 영상 제출 폼입니다.
     캠페인에 그 값이 없으면(예: 메일이 `{{google_form_url}}` 로만 적혀 있을 때) 그 칸만 나타나니 직접 넣어 주세요.
     Account ID 를 직접 넣을 때 계정이 여러 개면 띄어쓰기를 누르고 이어서 씁니다 — `@ID1, @ID2` 로 들어갑니다.
   - **사측 공유 파일**(필수): [첨부파일]로 pdf·pptx·docx·xlsx, 또는 노션 링크를 붙여넣고 Enter.
     파일 안에 든 **제품 사진도 같이 꺼내 둡니다**(「사진 N장」으로 표시됩니다).
   - **소구점**: 영상에서 반드시 보여 주고 강조할 점(한 줄에 하나)
   - **컨셉 설명**: 영상 전체의 흐름·타입
   - 브리프 이름은 넣지 않습니다 — 다 만든 뒤 내용을 보고 `[BRAND]US_TikTok_<제품명> _<컨셉> Guide` 로 영어 이름을 지어 줍니다.
     바꾸려면 [노션에 최종 생성] 창의 「노션 페이지 제목」에서 고칩니다.
2. **[생성]** — 2분쯤 뒤 오른쪽에 노션 모양 미리보기가 **한국어로** 나옵니다. 노션에 올라갈 **영어본도 이때 같이 만들어 둡니다**.
   1️⃣ 의 제품 사진은 공유 파일에서 **Claude 가 보고 골라** 자동으로 들어갑니다. 마음에 안 들면 눌러서 바꾸면 됩니다.
   - 다 만들면 **소리와 함께 윈도우 오른쪽 아래에 알림**이 뜹니다. 처음 [생성]을 누를 때 브라우저가 알림을 물으면 [허용]을 누르세요.
   - 만든 기획서는 그때 입력과 함께 **아카이브**(왼쪽 맨 위)에 쌓입니다. 누르면 그때 입력이 폼에, 만든 기획서가 미리보기에 다시 열립니다
     (그 뒤로 고친 것도 그대로). 다시 [생성]을 눌러도 앞의 기획서는 아카이브에 남습니다.
   - 만드는 동안 창을 닫아도 됩니다 — 결과는 아카이브에 남고, 다시 켜면 바로 열립니다.
3. 다듬기 — 고치고 싶은 곳을 **누릅니다**. 창이 두 가지로 열립니다.
   - **[직접 고치기]**: 글자만 있는 곳(문단·목록·자막·표 한 줄…)은 지금 글이 그대로 나옵니다. 고쳐 쓰고 [저장] — 기다림 없습니다.
   - **[Claude 에게 시키기]**: 스텝 전체처럼 여러 조각이 얽힌 곳은 이쪽만 됩니다. 어떻게 바꿀지 말로 적습니다.
   - **정해진 문구도 고칠 수 있습니다** — 스텝 제목 줄(`Step 2: …` — 번호는 순서대로 저절로, `(HOOK)`·⭐ 는 지우거나 붙여도 됨),
     스텝 소제목(`🩷 행동`·`👁 화면`… — [모든 스텝에 똑같이 바꾸기] 로 한 번에), 표의 항목 이름·머리줄, 🔴 금지 표현 표의 제목·머리.
     스텝 제목 줄을 누르면 [직접 고치기]는 그 줄, [Claude 에게 시키기]는 스텝 전체를 맡습니다.
   - 블록 **사이**에 마우스를 대면 「+ 여기에 추가」가 나옵니다. 직접 쓰거나 Claude 에게 시킬 수 있습니다.
   - **회색 네모**(사진 자리)를 누르면 공유 파일에서 찾은 사진 중에 고르거나, 내 컴퓨터에서 고릅니다.
   - 스텝의 **참고 GIF 자리**(회색 상자)를 누르면 상자 안에 **[레퍼런스 검색]** · **[영상으로 자동 생성]** · **[GIF 업로드]** 가 나옵니다.
     - **[레퍼런스 검색]** — 그 스텝 장면이 담긴 틱톡 영상을 찾을 **검색어 15개**를 만들어 줍니다(10초 안팎).
       검색어를 누르면 틱톡 검색이 새 탭으로 열립니다. [새로 고침]은 같은 기준으로 겹치지 않는 검색어를 다시 만듭니다.
     영상을 올리면 그 상자 안에서 올리기 → 처리 → 「구간 고르기」까지 보이고, 창은 구간을 고를 때만 뜹니다.
   - **한 자리에 영상을 여러 개** 고를 수 있습니다. 스텝의 행동이 여럿이면 행동마다 **가장 잘 보이는 영상**에서
     장면을 찾아 **순서대로 이어 붙인 것**을 후보 맨 위에 올려 줍니다(한 구간짜리 후보도 같이 나옵니다).
     예: 「병 라벨 보여 주기 → 패드 적시기」 스텝에 영상 2개 → 영상1의 라벨 클로즈업 + 영상2의 패드 적시기(자막 구간).
   - 창에는 조각마다 **어느 영상의 몇 초이고 어떤 행동을 맡는지**, 영상마다 **무엇이 있는지(안 쓴 영상은 왜 뺐는지)** 가 나옵니다.
     고른 장면은 AI 가 **실제 화면으로 한 번 더 확인**합니다 — 「화면 확인 통과/미흡」, 미흡한 후보는 아래로 내려갑니다.
     이어 붙인 것 중 안 맞는 조각은 빼고 다시 붙입니다.
   - **여러 상자에 한꺼번에 올려도 됩니다** — 올리기는 동시에 되고, Claude 처리는 올린 순서대로 하나씩 돕니다
     (기다리는 상자에는 「앞에 N개」가 보입니다). 같은 영상을 여러 스텝에 올리면 영상 읽기는 한 번만 합니다.
   - 잘못 고쳤으면 **[되돌리기]**(Ctrl+Z).
4. **[영어로 보기]** (선택) — 노션에 올라갈 영어본을 미리 봅니다(읽기 전용). 생성할 때 만들어 두었으니 바로 나옵니다.
   한국어를 고치면 **고친 줄만** 다시 옮깁니다(몇 초). 되돌리기로 돌아간 줄은 옮겨 둔 것을 그대로 씁니다.
5. **[노션에 최종 생성]** — 영어로 옮긴 뒤 Contents Guidline 아래에 새 페이지가 생깁니다.
   안 바꾼 사진 자리는 회색 이미지로 올라가니 노션에서 이미지를 눌러 「바꾸기」로 나중에 넣어도 됩니다.

적은 내용은 자동 저장됩니다. 창을 닫았다 열어도 그대로 돌아옵니다.

## 자주 묻는 것

- **[Claude 로그인]이 빨간색** — 눌러서 브라우저 로그인. 끝나면 초록색으로 바뀝니다.
- **"Claude 사용 한도에 걸렸습니다"** — 구독 한도입니다. 안내된 시각 뒤에 다시 하세요.
- **노션에 만들기가 "권한이 없습니다"** — 노션 승인 때 Contents Guidline 을 선택하지 않은 것입니다.
  오른쪽 위 노션 버튼 → [다시 연결].
- **캠페인 목록이 안 나온다 / [Kglowing API 확인 필요]** — 키가 없거나 바뀐 것입니다. 오른쪽 위 [Kglowing API] 에서 새 키를 넣으세요.
  그동안은 업로드폼·Account ID 칸이 나타나니 직접 넣으면 됩니다.
- **영상 기능을 처음 쓸 때** 영상 도구(ffmpeg·받아쓰기)를 한 번 내려받습니다(약 250MB, 1~2분).
  그다음부터는 바로 씁니다. 회사 네트워크가 GitHub 를 막으면 실패하니 그때는 알려 주세요.
- **약 6개월마다** 노션 승인을 다시 해야 합니다(노션 정책).
- 앱이 안 켜지면 로그를 보내 주세요: `%USERPROFILE%\.content-brief-studio\logs\app.err.log`

## 관리자

### 노션 통합 설정 (한 번)

파이널 리포트가 쓰는 노션 **공개 통합**을 재사용합니다. 통합 설정에서:

- **리디렉션 URI** 에 `http://localhost:4325/api/notion/oauth/callback` 을 **추가**(기존 URI 는 그대로)
- **기능(Capabilities)** 에서 콘텐츠 읽기 + **콘텐츠 삽입(Insert content)** 켜기

### 팀원에게 줄 것 두 가지

1. **팀 설정 코드**(노션 연결 정보) — `npm run team-code` 로 만듭니다.
   ```powershell
   npm run team-code
   ```
   client ID·secret 을 넣으면(시크릿은 화면에 안 보임, 이 PC 의 앱에 이미 있으면 Enter 로 그대로) `CBS1.…` 코드를 줍니다.
   팀원은 앱 오른쪽 위 [노션 설정]에 붙여넣습니다.
2. **Kglowing API 키**(X-API-KEY) — kglowing 외부 API 키 그대로. 팀원은 앱 오른쪽 위 [Kglowing API]에 붙여넣습니다.

둘 다 비밀값이니 **슬랙 DM 처럼 비공개로만** 전달하세요. 레포·공개 채널에 올리지 마세요.

### 안전장치

- 이 도구는 노션에 **설정된 부모 아래 새 페이지 만들기**만 합니다. 기존 페이지를 고치거나 지우는
  요청은 보내기 전에 코드가 막습니다(`src/notion/client.js` 쓰기 가드).
- 게시 도중 실패하면 만들던 페이지를 보관(휴지통) 처리해 반쪽 페이지가 남지 않게 합니다.
- 시크릿·토큰·초안은 전부 `%USERPROFILE%\.content-brief-studio\` 에만 있습니다. 레포는 공개입니다.

## 개발

```powershell
npm test                         # 단위 테스트 (Claude·노션 호출 없음)
$env:CBS_PORT=4326; npm start    # 설치본(4325)과 겹치지 않게
$env:CBS_NOTION_PARENT='<샌드박스 페이지 id>'   # 테스트 게시는 샌드박스로
```

규칙은 [CLAUDE.md](CLAUDE.md) 를 보세요. 의존성은 없습니다(`node:` 내장 모듈만).
마크다운 파서는 [markdown-it](https://github.com/markdown-it/markdown-it) (MIT) 를 `web/vendor` 에 담아 씁니다.
